What is UniVerify?

A quick overview before you start testing

UniVerify is a document authentication platform for Nigerian universities and institutions. When a university issues a certificate, transcript, or official letter, a unique QR code is embedded on the document. Anyone who scans that QR code can instantly verify the document is genuine.

This demo is running in test mode. No real money moves. You can test the full payment flow using the Paystack test card details provided below.

Generate a Document QR Code

Simulates what a university Registrar does when issuing a certificate
  1. Go to the Admin Dashboard at verify.akeenalee.com
  2. Fill in the Generate QR code panel. Example: Title = "B.Sc Computer Science", Issued To = "Amina Ibrahim", Issued By = "University of Abuja", Prefix = "UNIABJ".
  3. Click Generate QR code. A QR code appears with a unique Document ID like UNIABJ-20260516-EE18696D.
  4. Click Download PDF to see the full certificate PDF with the QR code embedded.

Verify as an Employer (Paid Flow)

Simulates what an employer or NYSC officer sees when they scan the QR code
  1. Take the verify URL from the QR result or construct it: verify.akeenalee.com/verify?doc=YOUR-DOC-ID
  2. Open the URL in your browser or scan the QR code with your phone camera. No app required.
  3. Since no student tokens exist yet, you are redirected to the payment page showing the document details and N1,000 fee.
  4. Enter any email address and click Pay and Verify.
  5. On the Paystack checkout page, use the test card details above.
  6. After payment you are redirected back and the Verified Authentic result is shown immediately.
Employer scans QR on smartphone. Payment page opens automatically showing document details and N1,000 one-time fee. No app required.
Secure Paystack checkout on mobile. Payment options: card, bank transfer, bank, and USSD. Secured by Paystack.
Document verified on mobile after payment. Green Verified Authentic badge with full certificate details: Document ID, title, graduate name, issuing university, document type, issue date, and exact verification timestamp (16/05/2026, 14:19:32).
This replaces the WAEC/NECO scratch card with instant digital payment. No scratch card, no bank branch, no USSD code to memorise. Payment completed on any smartphone in under 60 seconds.

Register as a Student and Buy Tokens

Simulates what a graduate does before sharing their certificate with employers
  1. Go to the Student Portal at verify.akeenalee.com/student.html
  2. Click Register here and fill in your matric number, institution, and a 4-8 digit PIN.
  3. After registering you see your portal showing 0 tokens.
  4. Click the Buy tokens tab and select a bundle (e.g. 3 verifications for N2,500).
  5. Enter an email for your receipt and click Proceed to payment.
  6. Use the test card to complete payment. Token balance updates immediately.
Graduate Amina Ibrahim registers on the UniVerify Student Portal. In a live institutional deployment, student accounts are pre-created from the university's student records system so graduates never need to register manually.

Instant Verification Using a Student Token

When a student has tokens, employer verification is instant with no payment page
To link a document to a student record, the document must be created with the student's matric number in the metadata field. In a live deployment this happens automatically at the point of document issuance from the student information system.
  1. Make sure you are logged into the Student Portal with at least 1 token.
  2. Visit the verify URL for a document linked to your matric number.
  3. The system checks your token balance. One token is deducted and the verified result is shown immediately with no payment page.
  4. Go to your Student Portal and check the Verification log tab to see the scan recorded.
Document verified instantly with no payment page when student has tokens. The system deducts one token automatically and displays the verified result in under one second. In a live institutional deployment, the institution name on the document and the student portal always match automatically since both are configured from the same system.

View the Audit Log

Every scan is logged. The institution sees everything.
  1. Go to the Admin Dashboard.
  2. Scroll down to the Verification log table.
  3. Every scan appears with document name, result badge, IP address, geographic location, device type, and exact timestamp.
  4. Click Refresh to pull the latest entries. The log auto-refreshes every 30 seconds.
UniVerify admin audit log showing verification scans across multiple documents. Each entry shows: document name, graduate name, Document ID, verified badge, IP address, geographic location, device type (Android, iPhone, Windows), and exact date and time. The institution has a permanent immutable record of every verification event.
The institution sees every employer who checked a document, from which country, on which device, and how they paid. Full visibility, full control.
