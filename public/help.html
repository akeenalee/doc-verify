What Is UniVerify?

Africa's permanent digital academic credential infrastructure

UniVerify is not a certificate verification website. It is a permanent digital credential infrastructure for Nigerian and African universities. Every certificate, transcript, attestation letter, admission letter, and official document carries a unique QR code. Anyone — employer, NYSC officer, embassy, or foreign university — can verify it instantly from anywhere in the world.

This is a live production platform running in test mode. All features shown here are operational today at verify.akeenalee.com.

Demo access is controlled. The admin dashboard requires demo credentials provided by Innovation Lens. Contact info@akeenalee.com to request access or ask for a personal demo link.

🔒 Demo Access

To access the admin dashboard, you need demo credentials or a personal token link. Contact info@akeenalee.com to request access. The graduate portal and verification pages are publicly accessible.

Generate a Document QR Code

Simulates what a Registrar does when issuing any official document
  1. Go to the Admin Dashboard. Log in with demo credentials if prompted.
  2. Fill in the Generate QR code panel. Try different Document type values to see the PDF layout change automatically.
  3. Set an ID prefix matching the institution (e.g. UNILAG, UNIABJ). Leave expiry date blank unless the document expires.
  4. Click Generate QR code. Unique Document ID and QR code appear instantly.
  5. Click Download PDF to see the full official document with embedded QR and demo signatures.
UniVerify Admin Dashboard. QR generation, verification panel, scan statistics, demo visitor count, and audit log.
QR code and Document ID generated instantly with institution prefix.
Generated degree certificate PDF with navy header, graduate name, degree title, document grid, QR code, demo signatures, and digital authentication footer.

Verify as an Employer

What an employer, NYSC officer, embassy, or foreign university sees
  1. Visit verify.akeenalee.com/verify?doc=YOUR-DOC-ID or scan the QR code with any smartphone. No app required.
  2. If no student tokens exist, you are redirected to the payment page showing document details and N1,000 fee.
  3. Enter any email and click Pay and Verify. Use the test card on the Paystack checkout.
  4. After payment, Verified Authentic is shown immediately including the actual document PDF embedded inline.
Employer scans QR on smartphone. Payment page opens automatically. No app required. Works from any country.
Paystack secure checkout. Card, bank transfer, bank, USSD. Under 60 seconds.
Document Verified on mobile. Green badge with full details and timestamp. The actual certificate or transcript PDF is embedded below so the employer sees exactly what the graduate holds.

Historical Certificates — No QR Code Needed

For documents issued before UniVerify was deployed

Graduates holding physical certificates with no QR code are fully covered. Two institution-controlled paths.

SOLUTION A
Search by Name or Matric

On the admin dashboard, use the Search by Name / Matric tab. Type the graduate's name or matric number. Institution's database returns the verified record instantly. Same result as scanning a QR.

SOLUTION B
Official Replacement PDF

Graduate logs into the Graduate Portal, goes to My Documents tab, and clicks Download Official PDF. Generated from the institution's database with QR embedded. Graduate cannot alter any detail.

The institution's database is always the source of truth. Both solutions route through authoritative institutional records. Students never control the verification result.
4

Graduate Portal

Every graduate from any graduation year has a personal verification account
  1. Go to verify.akeenalee.com/student.html and click Register here.
  2. Enter matric number, institution, and a 4-8 digit PIN. Email and phone are optional.
  3. Go to Buy tokens tab, select a bundle, use test card. Balance updates immediately.
  4. Go to My Documents tab to see all documents under your matric number and download official PDFs.
  5. Check Verification log to see every time your document was verified: who, when, where, and how they paid.
Graduate registers with matric number and PIN. In live deployment, accounts are pre-created from student records.
Four token bundles. Tokens never expire by time. A 2010 graduate can buy tokens in 2035.
Token balance credited immediately. Usable today, next year, or decades from now.
When a graduate has tokens, employer verification is instant. No payment page. One token deducted. Result under one second.

Instant Token Verification

No payment page, no delay
  1. Log into Graduate Portal with at least 1 token.
  2. Visit the verify URL for a document linked to your matric number.
  3. System deducts one token and shows verified result in under 1 second. No payment page.
  4. Check Verification log to see the scan recorded with timestamp and device details.
Verified instantly when graduate has tokens. Works identically for a 2026 certificate or one issued 20 years ago.

Institutional Audit Log

Every verification event permanently recorded
  1. Go to Admin Dashboard and scroll to the Verification log section.
  2. Click Demo Visitors tab to see everyone who accessed the demo with their full details.
  3. Every scan shows document, graduate, result, IP, location, device, and timestamp.
  4. Click Refresh or wait 30 seconds for auto-refresh.
UniVerify admin audit log. Every verification event permanently recorded. Append-only. No entry can ever be deleted.
The institution sees every employer who ever checked any document, from any year, from any country. Full visibility, full control, permanent record.
